NOVA FUNÇÃO: ADICIONAR ROUPAS PELO PRÓPRIO SITE

1. Abra index.html no navegador.
2. Vá até o catálogo e clique em “ADICIONAR / GERENCIAR PEÇAS”.
3. Escolha a foto da roupa.
4. Preencha nome e preço.
5. Escolha a condição: Usadas, Semi novas ou Nunca usadas.
6. Escolha o estilo: Paty, Baddie, Casual ou Mistura de Estilos.
7. Clique em “SALVAR PEÇA”.

A peça aparece imediatamente na aba correta. As peças adicionadas ficam salvas no navegador usando localStorage.

IMPORTANTE SOBRE PUBLICAÇÃO:
Este é um site estático. O formulário salva as novas peças apenas no navegador/dispositivo em que foram cadastradas; ele não cria um banco de dados online. Para colocar as novas peças na versão pública para todas as visitantes, use “EXPORTAR CATÁLOGO” e atualize o arquivo do site com os dados exportados (ou peça uma nova versão do site).

FOTOS:
O formulário aceita JPG, PNG, WEBP etc. Não é necessário renomear ou copiar a foto para a pasta assets quando estiver usando o formulário.

Também é possível editar o script.js manualmente. A estrutura de cada produto aceita:
name, price, condition, style, emoji, image e whatsappText.
